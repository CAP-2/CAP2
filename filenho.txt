Dự án: Gia Phả Việt - Cập nhật RBAC & Security (22/04/2026)

1. Backend:
- Loại bỏ so sánh plaintext password trong authController.js (chỉ dùng bcrypt).
- Thêm file config/roles.js để quản lý vai trò: admin (1), manager (2), member (3).
- JWT và response login hiện đã trả về role_name để frontend dễ xử lý.
- Đồng bộ hóa JWT_SECRET giữa controller và middleware.

2. Frontend:
- Cập nhật ProtectedRoute.jsx: hỗ trợ kiểm tra quyền truy cập dựa trên allowedRoles (tên vai trò).
- Cập nhật UserLayout.jsx: 
  + Tự động điều hướng người dùng sau khi đăng nhập thành công.
  + Tự động điều hướng nếu người dùng đã đăng nhập (có token) và truy cập vào trang chủ.
- Cập nhật routes/index.jsx: Phân nhóm các route theo vai trò (admin, manager, member) và áp dụng bảo vệ route nghiêm ngặt.

Quy tắc điều hướng:
- admin -> /dashboard
- manager -> /manager/account
- member -> /user/family-tree
