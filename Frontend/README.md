# Gia Pha Viet - ReactJS

Du an da duoc chuyen sang ReactJS su dung Vite va tach thanh cac component.

## Cau truc component

- `src/components/Header.jsx`
- `src/components/HeroBanner.jsx`
- `src/components/AboutSection.jsx`
- `src/components/GenealogySection.jsx`
- `src/components/FeaturesSection.jsx`
- `src/components/StatsSection.jsx`
- `src/components/SiteFooter.jsx`
- `src/App.jsx` de ghep layout tong

## Chay du an

```powershell
npm install
npm run dev
```

Mo trinh duyet tai URL in ra tu Vite (thuong la `http://localhost:5173`).

## Build production

```powershell
npm run build
npm run preview
```
